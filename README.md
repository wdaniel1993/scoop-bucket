# Scoop bucket for Lunate

`scoop bucket add lunate https://github.com/wdaniel1993/scoop-bucket && scoop install lunate`

The manifest in `bucket/lunate.json` points at `lunate-win-x64.zip` on
[the Lunate releases page](https://github.com/wdaniel1993/lunate/releases), with its
SHA-256. The canonical copy lives in the Lunate repository under `packaging/scoop/`;
`checkver`/`autoupdate` track later releases automatically.

Nothing is published here before the first tagged release exists.
